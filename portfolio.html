AIMemo

URL·텍스트·이미지를 던져 넣으면 기기 안의 AI가 요약하고 카테고리를 나눠 주는 메모 앱.

주요 기능

  • YouTube·Instagram·TikTok·웹 URL 공유 시 본문/자막/썸네일을 자동 수집
  • 온디바이스 LLM(Gemma, LiteRT)으로 요약·자동 분류 — 외부 AI 서버로 메모 미전송
  • 장소 메모는 주소 검색(Kakao) 후 Naver 지도에 표시
  • 독서 기록, 처리 큐/이력, AI 채팅 화면
  • Supabase 기반 로그인·클라우드 동기화(마지막 수정 우선, 소프트 삭제)

설계 포인트

  • 로컬 SQLite 우선 + 선택적 동기화로 오프라인에서도 동작
  • 모든 서버 테이블에 행 단위 보안(RLS) 적용, 본인 데이터만 접근
  • 백그라운드 큐와 포그라운드 서비스로 긴 AI 처리를 안정적으로 수행
  • 모델 다운로드·관리 화면 제공

기술 스택

AIMemo 저장

보고 있는 웹페이지를 한 번의 클릭으로 AIMemo에 저장하는 Chrome 확장 프로그램.

주요 기능

  • 제목·요약(og:description)·선택 텍스트·대표 이미지·URL을 메모로 저장
  • 같은 URL 중복 저장 방지, 카테고리 직접 선택
  • 저장된 메모 검색·카테고리 필터·상세 보기·삭제
  • 앱과 같은 계정으로 연동되어 다음 동기화 때 앱에 자동 반영

설계 포인트

  • SDK 없이 Supabase Auth/PostgREST를 직접 호출해 번들을 가볍게 유지
  • activeTab 중심의 최소 권한 — 사용자가 누른 순간만 페이지를 읽음
  • 리프레시 토큰 기반 세션 자동 갱신
  • 앱과 동일한 소프트 삭제 규칙으로 데이터 일관성 유지

기술 스택

로또 탐색기

“번호 추천”이 아니라 “내 로또 생활을 재미있게 관리”하는 개인화 로또 관리 서비스. 모든 조합의 확률이 같다는 점을 명시하는 책임 있는 설계.

주요 기능

  • 티켓 QR/사진 인식으로 구매 내역 등록, 당첨 자동 정산
  • 자동 가계부와 월 예산, 통계 대시보드
  • 주변·단골 판매점 지도, 단골점 당첨 소식과 회차 결과 푸시 알림
  • 결과 오픈·당첨번호 하이라이트 애니메이션
  • 문의/건의 게시판, 만 19세 미만 이용 제한

설계 포인트

  • QR(BarcodeDetector → jsQR)·판매점 코드(Tesseract OCR)를 브라우저 안에서만 처리, 사진 미전송
  • 동행복권 데이터를 크롤러(Cron)로 수집하고 파서 테스트(Vitest)로 형식 변경에 대비
  • 데이터 접근을 서버 API 한 곳으로 모아 본인 데이터만 조회
  • DB 설정 없이도 돌아가는 데모 모드 제공
  • 오프라인 화면과 서비스 워커를 갖춘 설치형 PWA

MotionTouch

얼굴 움직임만으로 스크롤·뒤로가기 등을 수행하는 핸즈프리 접근성 앱. 손을 쓰기 어려운 상황에서 화면을 조작할 수 있습니다.

주요 기능

  • 고개 좌/우/상/하 인식 → 18종 동작(스크롤, 연속 스크롤, 홈, 뒤로, 최근 앱, 탭, 스크린샷, 화면 잠금, 볼륨 등)에 연결
  • 앱별로 모션-동작 매핑을 따로 설정
  • 연속 스크롤 간격 조절, 얼굴 인식 상태 표시 오버레이

설계 포인트

  • ML Kit 얼굴 감지로 기기 안에서 실시간 분석 — 인터넷 권한 없음, 영상 저장·전송 없음
  • 포그라운드 카메라 서비스로 다른 앱 사용 중에도 계속 인식
  • 접근성 서비스의 제스처 API로 동작 수행, 화면 내용은 읽지 않음
  • 설정은 기기 내부 저장소(JSON)에만 보관
