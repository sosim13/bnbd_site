개인정보 처리방침

시행일: 2026년 11월 20일 (최종 수정: 2026년 11월 20일 — 파킹QR 항목 보완)

적용 앱: Fox Player (com.bnbd.foxplayer) 적용 앱: 파킹QR (com.parkingqr.parking_qr_app) 적용 앱: AIMemo (com.aimemo.aimemo) 적용 서비스: AIMemo 저장 (Chrome 확장 프로그램) 적용 서비스: 로또 탐색기 (웹/PWA) 적용 앱: MotionTouch (com.bnbd.motiontouch)
이 개인정보 처리방침은 bnbd(이하 "개발자")가 개발·배포·운영하는 모든 모바일 애플리케이션·웹 서비스에 공통으로 적용되는 통합 방침입니다. 현재 적용 대상은 Fox Player, 파킹QR, AIMemo(앱 및 Chrome 확장 프로그램), 로또 탐색기, MotionTouch이며, 개발자가 새로운 앱을 출시할 경우 별도 고지 없이 이 방침이 함께 적용될 수 있습니다. 앱별로 수집하는 정보 항목이 다르므로, 각 앱에 해당하는 섹션을 확인해 주세요.

1. 개인정보의 처리 목적

개발자는 각 앱이 제공하는 서비스의 목적 범위 내에서만 개인정보를 처리하며, 이용 목적이 변경되는 경우 관련 법령에 따라 별도의 동의를 받는 등 필요한 조치를 이행합니다.

2. 앱별 수집 항목 및 이용 목적

Fox Player com.bnbd.foxplayer

Fox Player는 기기에 저장된 음악 파일을 재생하는 로컬 뮤직 플레이어입니다. 회원가입·로그인 기능이 없으며, 서버로 어떠한 개인정보도 전송하지 않습니다.

수집 항목수집하지 않음 (개인을 식별할 수 있는 정보를 처리하지 않습니다)
접근 권한
  • 음악/오디오 파일 접근 권한 (READ_MEDIA_AUDIO) — 기기 내 음악 라이브러리를 스캔하기 위해 필요
  • 모든 파일 접근 권한 (MANAGE_EXTERNAL_STORAGE, 선택) — 가사(.lrc) 파일을 읽고 쓰기 위해 필요. 미허용 시에도 기본 재생 기능은 정상 동작
  • 알림 권한 — 재생 중 알림/잠금화면 컨트롤 표시
보관 위치사용자가 직접 입력한 가사, 즐겨찾기, 재생목록, 최근 재생 기록 등은 모두 기기 내부 저장소에만 저장되며 외부로 전송되지 않습니다.
제3자 제공없음

파킹QR com.parkingqr.parking_qr_app

파킹QR은 차량에 부착한 QR코드를 통해 방문자가 차주에게 전화·문자를 요청하고, 차주가 앱에서 이를 확인해 응답(전화 연결, 답장)할 수 있도록 중계하는 서비스입니다. 차주가 등록한 실제 전화번호는 방문자에게 공개되거나 제공되지 않습니다.

수집 항목 (차주/앱 이용자)
  • 구글 계정 정보 — 로그인은 구글 로그인으로만 이루어지며, 이메일·이름·프로필 사진·계정 식별자가 Firebase Authentication에 저장됩니다. (전화번호 인증 로그인은 제공하지 않습니다.)
  • 차량 프로필 정보 — 사용자가 직접 입력하는 차량번호, 표시 이름(선택). 방문자는 차량번호를 정확히 입력한 경우에 한해 해당 프로필을 조회할 수 있습니다.
  • 연락처 전화번호 — 차주가 프로필에 입력하는 번호. 본인만 열람할 수 있는 비공개 영역에 저장되며 방문자에게 공개하지 않습니다.
  • FCM 푸시 토큰 — 새 요청 도착 시 알림 발송을 위한 기기 식별 토큰
  • 수신한 연락 요청과 채팅 내용 — 아래 방문자 항목 및 차주가 보낸 답장
  • 기기에 저장되는 설정 — 빠른 답장 문구 등 (기기 내부 저장소에만 보관)
수집 항목 (방문자)
  • 방문자가 직접 입력하는 연락처(전화번호) 및 메시지 내용 — 별도 가입/로그인 없이 요청을 보낼 때에만 입력하며, 차주가 연락할 수 있도록 해당 차주에게 전달·표시됩니다. (푸시 알림에는 번호 일부가 가려진 형태로 표시될 수 있습니다.)
  • 브라우저 알림 토큰 — 방문자가 브라우저 알림을 허용한 경우에 한해, 차주의 답장을 알려주기 위해 해당 요청과 연결해 저장
  • 통화 연결을 위한 임시 정보 — 음성 통화를 요청한 경우 연결에 필요한 세션 정보와 네트워크 주소(IP 등)가 일시적으로 처리되며, 이름·전화번호와 함께 저장되지 않습니다.
  • 방문자 브라우저에는 입력한 번호가 편의를 위해 최대 3분간만 임시 저장되며, 이후에는 사용되지 않고 다음 접속 시 삭제됩니다.
접근 권한
  • 카메라 — QR코드 스캔 (촬영된 영상/이미지를 저장하거나 서버로 전송하지 않음)
  • 마이크 — 앱·웹 내 음성 통화(WebRTC) 기능 사용 시에만 활성화되며, 통화 내용을 서버에 저장하거나 녹음하지 않음 (통화는 당사자 간 직접 연결)
  • 알림 — 요청 도착 시 푸시 알림 표시
  • 포그라운드 서비스(마이크 유형) — 앱이 백그라운드에 있을 때에도 전화 요청을 수신하기 위해 사용
이용 목적 전화·문자 중계 서비스 제공, 차주 본인 확인(로그인), 요청 알림(FCM 푸시) 발송, 음성 통화 연결, 서비스 부정이용 방지
보관 위치 및 제3자 제공 수집된 정보는 서비스 제공을 위해 Google Firebase(Authentication, Firestore, Realtime Database, Cloud Messaging, Hosting)에 저장·처리되며, 푸시 알림 발송을 중계하는 서버 함수는 Supabase(Edge Functions)에서 실행됩니다. 이 서버 함수는 알림 내용(마스킹된 번호, 메시지 앞부분)을 전달하는 용도로만 처리하며 별도로 저장하지 않습니다. 음성 통화 연결 시 네트워크 주소 확인을 위해 Google의 공개 STUN 서버를 이용합니다. 위 사업자는 개발자가 이용하는 클라우드 인프라(개인정보처리 위탁업체)이며 해외(미국 등)의 서버에서 처리될 수 있습니다. 이 외의 목적으로 제3자에게 제공되지 않습니다.
계정·데이터 삭제 앱의 설정 > 계정 삭제에서 직접 삭제할 수 있습니다. 삭제 시 프로필, 전화번호, 받은 요청·채팅, 푸시 토큰, 로그인 계정이 즉시 영구 삭제됩니다. 앱을 사용할 수 없는 경우의 요청 방법은 계정 및 데이터 삭제 안내와 아래 문의처를 확인해 주세요.

AIMemo com.aimemo.aimemo

AIMemo는 URL·텍스트·이미지를 메모로 저장하고 AI가 요약·분류해 주는 메모 앱입니다. AI 분석은 기기 안에서 동작하는 온디바이스 모델(Gemma)로 처리하며, 메모 내용을 외부 AI 서비스로 전송하지 않습니다.

수집 항목
  • 구글 계정 정보 — 구글 로그인 이용 시 이메일, 이름, 계정 식별자
  • 이용자가 작성·저장한 메모 데이터 — 제목, 내용, 카테고리, 원본 URL, 썸네일/첨부 이미지, 주소·검색어·좌표(장소 메모), 독서 기록, 처리 이력
접근 권한
  • 인터넷 — 로그인, 클라우드 동기화, URL 본문·지도 정보 조회
  • 위치(ACCESS_FINE_LOCATION, ACCESS_COARSE_LOCATION) — 지도에서 현재 위치 표시. 현재 위치는 서버에 저장하지 않음
  • 알림 / 포그라운드 서비스(데이터 동기화) — 백그라운드 메모 처리 진행 상태 표시
보관 위치 메모는 우선 기기 내부 DB에 저장되며, 로그인 후 동기화를 사용하면 Supabase에 저장됩니다. 서버 데이터는 행 단위 보안(RLS)으로 본인 계정만 접근할 수 있습니다. 앱 설정값은 기기의 보안 저장소에 보관됩니다.
외부 서비스 이용 이용자가 저장한 URL의 본문·썸네일 조회(YouTube, Instagram, TikTok 등 해당 사이트), 주소 검색(Kakao Local), 지도 표시(Naver Map)를 위해 해당 서비스에 요청이 전송될 수 있습니다.
제3자 제공없음

AIMemo 저장 Chrome 확장 프로그램

현재 보고 있는 웹페이지를 AIMemo 계정에 저장하고 저장된 메모를 조회하는 확장 프로그램입니다. 이용자가 저장 버튼을 누른 경우에만 동작하며, 브라우징 기록을 수집하지 않습니다.

수집 항목
  • 이용자가 저장을 실행한 페이지의 제목, 요약(og:description), 선택한 텍스트 또는 본문 발췌, 대표 이미지 주소, 원본 URL
  • 구글 로그인 인증 정보(이메일, 로그인 토큰)
사용 권한
  • activeTab, scripting — 이용자가 저장을 누른 현재 탭의 내용을 읽기 위해 사용
  • storage — 로그인 세션을 브라우저 로컬 저장소에 보관
  • identity — 구글 로그인(OAuth) 진행
  • Supabase 호스트 접근 — 메모 저장·조회
보관 위치 및 제3자 제공 저장된 메모는 AIMemo 앱과 동일한 Supabase 계정 영역에 저장되며, 제3자에게 제공하지 않습니다. 광고·분석 목적으로 사용하지 않습니다.

로또 탐색기 웹/PWA

로또 탐색기는 구매한 로또 티켓 기록, 당첨 정산, 가계부, 주변 판매점 정보를 제공하는 개인 로또 관리 서비스입니다. 통계 참고 도구이며 당첨을 보장하지 않습니다. 만 19세 이상만 이용할 수 있습니다.

수집 항목
  • 이메일 가입: 이메일, 비밀번호(암호화 저장), 이름
  • 구글 로그인 이용 시: 이메일, 이름, 프로필 이미지 주소, 계정 식별자
  • 생년월일 — 만 19세 미만 이용 제한 및 생일수 번호 구성
  • 티켓 로그·가계부 — 회차, 구매일시, 판매점, 게임 번호, 구매 금액, QR 원문, 당첨 정산 결과, 단골 판매점, 월 예산, 알림 설정
  • 푸시 알림 이용 시: 푸시 토큰, 기기 구분
  • 문의/건의 이용 시: 제목, 내용, 분류
  • 자동 수집: 로그인 세션 정보(세션 토큰, 접속 IP, 브라우저 정보), 쿠키
서버에 저장하지 않는 정보
  • 티켓 사진 원본 — QR·판매점 코드 인식은 기기(브라우저) 안에서만 처리되며 서버로 전송하지 않음
  • 기기 위치 — 주변 판매점 표시·알림에만 사용하며 저장하지 않음
접근 권한 카메라(티켓 QR 촬영, 선택), 위치(주변 판매점, 선택), 알림(당첨 소식·예산 알림, 선택)
보관 위치 및 위탁 Neon(데이터베이스, 싱가포르 리전), Google(로그인, Firebase 푸시), Kakao(카카오맵)를 이용합니다. 회원 탈퇴 시 계정의 티켓, 단골점, 푸시 토큰, 문의 내용이 함께 삭제됩니다.

MotionTouch com.bnbd.motiontouch

MotionTouch는 전면 카메라로 얼굴 움직임(고개 방향 등)을 인식해 화면 스크롤·뒤로가기 같은 터치 동작을 대신 수행하는 접근성 보조 앱입니다. 인터넷 권한을 사용하지 않으며, 모든 처리는 기기 안에서만 이루어집니다.

수집 항목수집하지 않음 (서버로 전송·저장되는 개인정보 없음)
접근 권한
  • 카메라 / 카메라 포그라운드 서비스 — 얼굴 움직임을 실시간 분석하기 위해 사용. 영상·이미지는 저장하거나 외부로 전송하지 않음
  • 접근성 서비스 — 인식된 동작을 스크롤·탭 등 제스처로 수행하기 위해 사용. 화면 내용은 읽지 않으며(canRetrieveWindowContent=false), 현재 실행 중인 앱의 패키지명만 앱별 설정 적용에 사용
  • 설치된 앱 목록 조회 — 앱별 동작 설정 화면에서 앱을 선택하기 위해 사용 (외부 전송 없음)
  • 알림 / 배터리 최적화 제외 요청 — 카메라 서비스가 백그라운드에서 유지되도록 하기 위해 사용
보관 위치앱별 동작 설정 등은 기기 내부 저장소에만 저장됩니다.

4. 개인정보의 보유 및 이용 기간

  • Fox Player: 서버에 개인정보를 보관하지 않으며, 앱 내 데이터는 사용자가 앱을 삭제하거나 데이터를 직접 삭제할 때까지 기기에만 보관됩니다.
  • AIMemo(앱·확장 프로그램): 계정 삭제 또는 메모 삭제 시 해당 데이터를 파기합니다. 앱 내 삭제는 동기화를 통해 서버에 반영됩니다(삭제 표시 후 파기).
  • 로또 탐색기: 회원 탈퇴 또는 삭제 요청 시까지 보관하며, 탈퇴 시 티켓·단골점·푸시 토큰·문의 내용을 함께 삭제합니다.
  • MotionTouch: 서버에 개인정보를 보관하지 않으며, 설정 데이터는 앱 삭제 시까지 기기에만 보관됩니다.
  • 파킹QR: 차주가 앱에서 계정을 삭제하면 프로필·전화번호·받은 요청과 채팅·푸시 토큰·로그인 계정을 지체 없이 삭제하고, 프로필을 삭제하면 프로필·전화번호·QR 링크를 삭제합니다. 방문자가 남긴 요청·메시지는 차주가 삭제하거나 차주 계정이 삭제될 때까지 보관되며, 별도의 자동 삭제 기간은 두지 않습니다. 단, 관계 법령에 따라 보존이 필요한 경우 해당 기간 동안 별도 보관합니다.
